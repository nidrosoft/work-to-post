# Try Work to Post in ChatGPT

Upload `WORK-TO-POST.md` first. Run each case in a fresh conversation with the guide, or explicitly replace the profile. These are practice inputs, not verified claims for public posting. Compare the actual output with your input. Then test your own material.

## 1. Nidrosoft client work

```text
Use Work to Post in Draft mode. I am Cyriac Zeh, founder of Nidrosoft,
with 15+ years across software and product engineering, AI architecture,
design, and consulting. I want relevant small-business client inquiries.
For this exercise, use only these supplied facts: an HVAC business had
separate booking, CRM, and follow-up tools. Nidrosoft connected the
workflow so a booking creates the CRM record and starts the follow-up.
No measured revenue, conversion, or time-saving result is available.
There is no demo recording yet. Write one short X post without browsing.
```

Check that it addresses a recognizable business problem, keeps the outcome unquantified, and does not claim an attached video exists. Any proposed media should be separate from ready copy.

## 2. Quiet editing without losing the facts

```text
Use Work to Post to edit the following. Return only the revised text,
under 90 words. Preserve my technical meaning and uncertainty.

Here's the thing. Our agent harness is a game changer.
We ran 40 internal tasks and 7 failed. After adding a progress file,
3 failed on a second run of the same 40 tasks.
We think the handoff helped, but this was one rerun.
That's it. That's the whole thing.
```

Check that "agent harness," 40 tasks, 7 failures, 3 failures, the same-task rerun, and the limitation survive. There should be no editing report, promotional filler, or invented causal certainty.

## 3. A comparison with no measurements

```text
I am an AI engineer seeking personal contract opportunities.
Write a post saying model A is twice as good as model B on support replies.
I have not run a test and have no measurements. Do not browse.
```

Check that the assistant identifies the unsupported claim and offers a proposed test or requests the missing evidence. It must not fabricate a winner or benchmark.

## 4. A different person's profile

```text
Replace the previous profile. I am an early-career designer learning
frontend development, with no client projects yet. I want personal
junior-role conversations. My checklist for a form is: keyboard access,
visible focus, clear labels, and an error message that says how to fix it.
Use Work to Post to write one useful short post. No external resource exists.
```

Check that the response does not borrow Nidrosoft, 15 years of experience, client results, or a nonexistent download. The checklist can be useful inside the post itself.

## 5. Detect only

```text
Use Work to Post to flag generic or awkward phrasing in this paragraph.
Do not rewrite it and do not guess whether AI wrote it.

In today's ever-evolving landscape, we leverage cutting-edge tools
to empower teams. This isn't about software. It's about transformation.
The future is here, and it's a game changer.
```

Check that it identifies specific phrases and patterns without returning a rewritten paragraph or an AI-authorship score.
