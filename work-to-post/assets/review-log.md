# Post and opportunity log

Keep this in a private working copy. One post may connect to several opportunities, and one opportunity may involve several posts. Do not count the same opportunity again each time it progresses.

## Post record

```text
Post ID and URL:
Published date:
Intended reader:
Primary outcome:
Topic and use case:
Primary angle ID:
Series name and installment, if any:
Format and proof:
Main claim and source:
Call to action, if any:

48-hour snapshot, with missing metrics left blank:
7-day snapshot, with missing metrics left blank:
Views, replies, saves, and other available engagement:
Relevant questions or objections received:
What to test next:
```

## Opportunity record

```text
Opportunity ID:
Track: CLIENTS / OFFERS
Real project or role, with company where known:
Stage: 1 qualified inquiry / 2 call or interview / 3 agreement, offer, or hire
Evidence and date:
Attribution: exact post / named series or format / profile or account / unknown
Which post or series was named, if any:
Current status and next action:
```

Record CLIENTS and OFFERS independently. For a post-level summary, show the highest evidenced stage and the number of unique opportunities in each track. Use 0 for no observed qualifying evidence, and leave the score blank if it has not been reviewed. Zero does not establish that no private outcome occurred.

A compliment, a follow, an anonymous "DM me," or a resource download is not a qualified work opportunity. Keep these in engagement. A consulting inquiry belongs in the track matching how the engagement is actually being offered. Resolve ambiguous cases before assigning both tracks.
